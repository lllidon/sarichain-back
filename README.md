# بک‌اند ساری چین

NestJS، TypeScript و MongoDB. ماژول `auth` با نام کاربری یا شماره موبایل ایران و رمز عبور وارد می‌شود و توکن JWT یک‌ساعته برمی‌گرداند.

## راه‌اندازی محلی

به Node.js نسخه ۲۲ یا بالاتر و یک سرور MongoDB نیاز دارید. برنامه از دیتابیس `sarichain` و مجموعه `users` استفاده می‌کند.

```bash
npm ci
cp .env.example .env
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

خروجی دستور آخر را به‌عنوان `JWT_SECRET` در `.env` بگذارید. در صورت نیاز نشانی MongoDB را با `MONGODB_URI` تنظیم کنید. روی محیط اشتراکی، رازها را از طریق متغیرهای محیطی یا مدیر اسرار وارد کنید.

```bash
npm run build
read -r -p 'Mobile: ' AUTH_USER_PHONE
read -r -s -p 'Password: ' AUTH_USER_PASSWORD
printf '\n'
AUTH_USER_PHONE="$AUTH_USER_PHONE" AUTH_USER_PASSWORD="$AUTH_USER_PASSWORD" npm run auth:create-user
unset AUTH_USER_PHONE AUTH_USER_PASSWORD
npm start
```

اسکریپت مدیریت کاربر به Bash نیاز دارد. یک شماره موبایل ایران و رمز ۸ تا ۱۲۸ کاراکتری برای کاربر اولیه وارد کنید. رمز در MongoDB به‌شکل هش scrypt ذخیره می‌شود. برای توسعه با بارگذاری خودکار، از `npm run start:dev` استفاده کنید.

## مدیر اولیه

برای ساخت خودکار حساب `milad`، مقدار `BOOTSTRAP_ADMIN_PASSWORD` را در فایل محلی `.env` یا تنظیمات محیط اجرا تعیین کنید. بک‌اند هنگام شروع، فقط اگر مجموعه `users` خالی باشد این حساب را با نقش `admin` می‌سازد. داده‌های موجود و رمز حساب در اجراهای بعدی تغییر نمی‌کنند. پس از ساخت، می‌توانید متغیر اولیه را از محیط اجرا حذف کنید. دسترسی خواندن کاتالوگ همچنان برای حساب‌های دارای توکن معتبر فعال است.

## Swagger

- [Swagger UI](http://localhost:3001/docs)
- [OpenAPI JSON](http://localhost:3001/docs-json)

در Swagger عملیات `POST /auth/login` را باز کنید و `password` را همراه با یکی از `phone` یا `username` بفرستید. شماره در قالب `09123456789` یا `+989123456789` پذیرفته می‌شود. پاسخ موفق شامل `accessToken`، `tokenType` و `expiresIn` است.

## مدل کاتالوگ

ماژول‌های `categories`، `brands` و `products` به‌ترتیب مجموعه‌های هم‌نام را در دیتابیس `sarichain` تعریف می‌کنند. ساخت رکورد از طریق سرویس‌های داخلی NestJS انجام می‌شود. مسیر خواندن `GET /catalog/:collection` برای پنل در Swagger مستند شده است. مقدار `collection` یکی از `products`، `categories` و `brands` است. توکن ورود را با هدر `Authorization: Bearer <token>` بفرستید. پارامترهای `search`، `page` و `limit` اختیاری‌اند.

هر سه مدل `name`، `slug` یکتا در مجموعه، `imageUrl`، `thumbnailUrl`، `shortDescription`، `description`، `isActive` و زمان ایجاد و ویرایش دارند. `slug` بخش خوانای نشانی صفحه است. برند سلسله‌مراتب ندارد.

- **دسته‌بندی** با `parentId` و `level` ذخیره می‌شود. سرویس سطح را از والد محاسبه می‌کند. نمونه: مواد غذایی ← میوه ← مرکبات. والد پس از ایجاد ثابت است و سطح چهارم رد می‌شود.
- **محصول** با `sku` یکتای سایت و `itemId` اختیاری از سیستم حسابداری ذخیره می‌شود. محصول اصلی (`master`) دسته، برند اختیاری و `basePrice` دارد. گزینه محصول (`variant`) فقط به یک محصول اصلی وصل می‌شود و دسته و برند آن را به ارث می‌برد. هر گزینه SKU خودش را دارد و می‌تواند مشخصه‌هایی مانند روش کشت داشته باشد.
- **قیمت** مبلغ صحیح در کوچک‌ترین واحد ارز همراه با کد سه‌حرفی ارز است. برای ریال، `IRR` و مبلغ به ریال ذخیره می‌شود. قیمت پایه گزینه از جمع مبلغ پایه محصول اصلی و `priceAdjustment` به‌دست می‌آید. تعدیل می‌تواند منفی، صفر یا مثبت باشد.
- **مشخصات فیزیکی** شامل چگالی استاندارد بر حسب کیلوگرم بر مترمکعب، وزن حمل بر حسب گرم و طول، عرض و ارتفاع بسته بر حسب میلی‌متر است.

برای مثال، «خیار محلی» می‌تواند محصول اصلی و «خیار محلی گلخانه‌ای» گزینه‌ای با SKU مستقل و تعدیل قیمت باشد. فروشنده، قیمت پیشنهادی و شرایط فروش به پیشنهاد فروشنده تعلق دارند و در مدل محصول ذخیره نمی‌شوند.
